Getting Started

This page walks you from a fresh clone to a working sprite_utils draw invocation.

Prerequisites

RequirementDetails
C++ compilerGCC ≥ 13, Clang ≥ 17, or MSVC with C++23 support
CMake≥ 3.25.1
OpenCVAny recent version (4.x recommended); must be findable by CMake via find_package(OpenCV)
GitTo clone the repository

Installing OpenCV on Debian/Ubuntu

sudo apt-get install libopencv-dev

Installing OpenCV on Fedora/RHEL

sudo dnf install opencv-devel

Installing OpenCV on macOS (Homebrew)

brew install opencv

Step 1 — Clone

git clone https://github.com/openeggbert/sprite-utils.git
cd sprite-utils

Step 2 — Configure and Build

# Configure (out-of-source build recommended)
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Build
cmake --build build --parallel

On success the binary is at build/sprite_utils.

Debug Build

Use -DCMAKE_BUILD_TYPE=Debug for a debug build with symbols. Useful for debugging crashes.

Step 3 — Verify the Build

./build/sprite_utils version
# Expected: Sprite Utils 0.0.0-SNAPSHOT

./build/sprite_utils help

Step 4 — Prepare a Sprite Sheet CSV

sprite-utils needs a semicolon-delimited CSV file describing where each sprite lives on its image. See File Formats for the full specification, or CSV Format Tutorial for a walkthrough.

Minimal example (spritesheet.csv):

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
player.bmp;walk;1;1;1;;0;32;32;;;

Step 5 — Run the draw Command

# Process all images in /path/to/sprites using spritesheet.csv in the same dir
./build/sprite_utils draw --dir /path/to/sprites

# Or specify the CSV explicitly
./build/sprite_utils draw \
  --dir /path/to/sprites \
  --sprite-sheet-path /path/to/spritesheet.csv

After running, each processed image will have dashed rectangles drawn around the defined sprites. The original image is preserved as imagefile.bmp.backup.

What Happens Next

  • Open the modified images in any image viewer to check sprite boundaries.
  • If a boundary is wrong, fix the CSV and re-run — the tool restores from the backup automatically.
  • A spritesheet.csv.computed.csv file is written alongside the CSV with resolved coordinates for inspection.

Backup Safety

On the first run, the tool creates .backup files. On subsequent runs it restores from those backups before drawing again. If you delete the backup files, the annotations become permanent.
