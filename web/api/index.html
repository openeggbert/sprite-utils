API Index

sprite-utils is a command-line tool, not a library. There is no public API for external use. This section documents the internal C++ classes for developers working on the codebase.

See All Classes for the full class reference.

Enum vs Implementation

SpriteUtilsCommand is declared but not currently used in the dispatcher. The dispatcher uses string comparison, not this enum.
