sprite-utils Documentation

sprite-utils is a C++23 command-line tool for working with sprites in game asset pipelines. It reads a CSV sprite-sheet definition file, then draws labelled dashed rectangles onto source image files — making it easy to visually audit sprite coordinates before cutting or exporting them.

It is part of the Open Eggbert / Free Eggbert game project ecosystem and is authored by Robert Vokac (MIT licence, 2023–2025).

Note

The current version is 0.0.0-SNAPSHOT. The project is in active development. Some commands listed in source code (restore, extract, gifs) are not yet implemented.

Quick Start

# 1. Clone the repo
git clone https://github.com/openeggbert/sprite-utils.git
cd sprite-utils

# 2. Build with CMake (requires OpenCV)
cmake -B build
cmake --build build

# 3. Run on your sprite directory
./build/sprite_utils draw \
  --dir /path/to/sprites \
  --sprite-sheet-path /path/to/spritesheet.csv

Key Features

  • Reads sprite coordinates from a semicolon-delimited CSV sprite-sheet file.
  • Draws dashed coloured rectangles around each defined sprite on the source image.
  • Optionally draws sprite sequence numbers in a small bitmap font (single or double-sized).
  • Preserves the original bit-depth of BMP files (8-bit, 16-bit RGB565).
  • Handles BLP files as 16-bit RGB565 BMP (game-engine format).
  • Creates and restores automatic backups (`.backup` extension) before modifying images.
  • Generates a .computed.csv file with resolved coordinates.
  • Supports filtering by filename (--file-name) or row (--row).
