Command-Line Reference

Synopsis

sprite_utils [command] [--option value] ...

The first argument is the command name. If omitted, draw is assumed (source: src/SpriteUtilsArgs.cpp line 28). All subsequent arguments must be in --key value pairs.

Option Syntax

All options start with -- and require a following value. Options without a value are not supported. Boolean options accept true or false as the value string.

Available Commands

CommandStatusDescription
drawImplementedDraw dashed rectangles and numbers on sprite images
helpImplementedDisplay help text
versionImplementedDisplay version string
restorePlannedRestore images from backups (enum defined, not wired)
extractPlannedExtract sprites (enum defined, not wired)
gifsPlannedGIF generation (enum defined, not wired)

Command: draw

Reads the sprite-sheet CSV, iterates image files in the working directory, draws dashed rectangles and optional numbers on each image, and saves the result back preserving the original bit-depth.

Options

OptionTypeDefaultDescription
--dir path string . (current dir) Working directory containing image files to process. All files in this directory are iterated.
--sprite-sheet-path file path <dir>/spritesheet.csv Path to the semicolon-delimited CSV sprite-sheet definition file.
--file-name filename string (process all files) If specified, only this file (by name, not path) is processed. Processing stops immediately after.
--row integer (all rows) If specified, only sprite rows with this row number are drawn.
--draw-number boolean true Whether to draw the sprite sequence number inside each rectangle.
--draw-number-background boolean true Whether to draw a white background rectangle behind the number.
--double-sized-number boolean false If true, use the larger (10×6 pixel) digit font. Automatically falls back to small font if the sprite width is less than 23 pixels.
--rectangle-color RGB string 255,0,0 (red) Colour of the dashed rectangle border as comma-separated RGB values, e.g. 0,255,0 for green.

Examples

# Minimal: process all files in current dir using ./spritesheet.csv
sprite_utils draw

# Specify directory and CSV
sprite_utils draw --dir /game/assets --sprite-sheet-path /game/sprites.csv

# Process only one file
sprite_utils draw --dir /game/assets --file-name player.bmp

# Only draw row 2 of sprites on player.bmp
sprite_utils draw --dir /game/assets --file-name player.bmp --row 2

# Green rectangles, no numbers
sprite_utils draw \
  --dir /game/assets \
  --rectangle-color 0,255,0 \
  --draw-number false

# Double-sized numbers with no background
sprite_utils draw \
  --dir /game/assets \
  --double-sized-number true \
  --draw-number-background false

Output

  • Modified image files (in-place in --dir)
  • <imagefile>.backup — backup of the original, created on first run and used for restore on subsequent runs
  • <sprite-sheet-path>.computed.csv — computed CSV with all coordinates resolved

Command: help

Prints usage information to stdout. No options required.

sprite_utils help

Command: version

Prints the version string to stdout.

sprite_utils version
# Output: Sprite Utils 0.0.0-SNAPSHOT

Error Handling

If an unknown command is provided, sprite-utils prints:

Command "xyz" is not supported.

followed by the help text, then throws a SpriteUtilsException which propagates to main and terminates the process. Exit code is non-zero in this case (standard C++ unhandled exception behaviour).

Invalid option syntax (missing value, value starting with --) also throws a SpriteUtilsException.
