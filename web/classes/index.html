Command

Header: include/Command.h

Abstract base class for all commands. Defines the interface every command must implement.

class Command {
public:
    virtual ~Command() = default;
    virtual std::string getName() const = 0;
    virtual std::string run(const SpriteUtilsArgs& args);
};

The default run() throws SpriteUtilsException("Not yet implemented."). Concrete subclasses override it.

Color

Header: include/SpriteUtilsOptions.h

Simple RGB(A) colour struct. The alpha field exists but is not used in drawing (OpenCV uses BGR without alpha for these operations).

struct Color {
    int r{}, g{}, b{}, a{};
    static const Color RED;  // {255, 0, 0, 0}
};

SpriteUtils

Header: include/SpriteUtils.h — Impl: src/SpriteUtils.cpp

Main application class. Holds the command registry and dispatches to the appropriate command.

class SpriteUtils {
public:
    SpriteUtils();
    void run(const std::vector<std::string>& args);
    void run(const SpriteUtilsArgs& args);
private:
    std::unordered_map<std::string, std::unique_ptr<Command>> commandImplementations;
};

SpriteUtilsException

Header: include/SpriteUtilsException.h

Custom exception. Inherits std::runtime_error. Has three constructors: message only, message + cause, cause only.

class SpriteUtilsException : public std::runtime_error {
public:
    explicit SpriteUtilsException(const std::string& msg);
    SpriteUtilsException(const std::string& msg, const std::exception& e);
    explicit SpriteUtilsException(const std::exception& e);
};
