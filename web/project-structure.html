Project Structure

A detailed map of the sprite-utils repository layout.

Directory Tree

sprite-utils/
├── CMakeLists.txt          Build definition
├── LICENSE                 MIT licence text
├── README.md               Minimal README (badges only)
├── CREDITS                 Author credits
├── header.txt              MIT licence header for source files
├── .clangd                 Clangd config (adds -std=c++23)
├── .gitignore              Git ignore rules
├── add_license_after_includes.sh  Script to prepend licence header
├── numbers.png             Small digit font reference image
├── numbers_double_sized.png  Large digit font reference image
│
├── include/                Public header files
│   ├── Command.h           Abstract command interface
│   ├── DrawCommand.h       draw command declaration
│   ├── HelpCommand.h       help command declaration
│   ├── VersionCommand.h    version command declaration
│   ├── SpriteUtils.h       Main dispatcher class
│   ├── SpriteUtilsArgs.h   Argument parser
│   ├── SpriteUtilsOptions.h Typed options accessor
│   ├── SpriteUtilsCommand.h Command enum (DRAW,RESTORE,EXTRACT,GIFS,HELP,VERSION)
│   ├── SpriteUtilsException.h Custom exception class
│   ├── SpriteSheet.h       CSV sprite-sheet reader
│   ├── SpriteSheetRow.h    CSV row data model
│   └── Utils.h             File I/O and string utilities
│
├── src/                    Implementation files
│   ├── Main.cpp            Entry point
│   ├── SpriteUtils.cpp     Dispatcher + command registry
│   ├── DrawCommand.cpp     Image annotation (largest file)
│   ├── HelpCommand.cpp     Help text output
│   ├── VersionCommand.cpp  Version string output
│   ├── SpriteSheet.cpp     CSV parsing + computed CSV write
│   ├── SpriteSheetRow.cpp  CSV row parse + serialise
│   ├── SpriteUtilsArgs.cpp Argument parsing
│   ├── SpriteUtilsOptions.cpp Typed option getters
│   └── Utils.cpp           File I/O helpers
│
└── .idea/                  CLion IDE project files (not part of build)

Source Files Reference

FileRoleSize / Complexity
src/Main.cppEntry point, minimalSmall
src/SpriteUtils.cppCommand dispatcherSmall
src/DrawCommand.cppCore annotation engineLarge (~630 lines)
src/SpriteSheet.cppCSV parsing, validation, computed CSV outputMedium
src/SpriteSheetRow.cppRow data model, CSV serialisationSmall
src/SpriteUtilsArgs.cppargv parsing into key-value mapSmall
src/SpriteUtilsOptions.cppTyped option accessorsSmall
src/Utils.cppFile read/write, string split, dir listingSmall
src/HelpCommand.cppHelp text (static string)Trivial
src/VersionCommand.cppVersion string outputTrivial

No Tests, Examples, or Scripts of Note

  • No test/ directory.
  • No examples/ directory.
  • add_license_after_includes.sh — a maintenance script that prepends the MIT header after include statements. Not part of the build.

Generated Files (Not in Repository)

The build process produces:

  • build/sprite_utils (or build/sprite_utils.exe on Windows)
  • CMake cache and build system files in build/

Runtime generates:

  • *.backup files next to processed images
  • spritesheet.csv.computed.csv next to the input CSV
