Architecture

High-Level Structure

sprite-utils uses a simple command pattern: a central dispatcher (SpriteUtils) holds a map of command-name → command-object, parses the first argument as the command name, and delegates to the appropriate handler. 

main()
  └─ SpriteUtils::run(args)
       ├─ SpriteUtilsArgs (parse argv)
       └─ Command dispatch → DrawCommand / HelpCommand / VersionCommand

Layer Diagram

┌─────────────────────────────────────────────────────────┐
│  CLI layer: Main.cpp                                    │
│  SpriteUtils (dispatcher + command registry)            │
├─────────────────────────────────────────────────────────┤
│  Command layer                                          │
│  ├─ DrawCommand    (image annotation pipeline)          │
│  ├─ HelpCommand    (text output)                        │
│  └─ VersionCommand (text output)                        │
├─────────────────────────────────────────────────────────┤
│  Domain layer                                           │
│  ├─ SpriteSheet    (CSV parsing + map)                  │
│  ├─ SpriteSheetRow (row data model + CSV serialize)     │
│  ├─ SpriteUtilsArgs   (raw arg key-value store)         │
│  └─ SpriteUtilsOptions (typed option accessors)         │
├─────────────────────────────────────────────────────────┤
│  Utility layer                                          │
│  └─ Utils (file I/O, string split, dir listing)         │
├─────────────────────────────────────────────────────────┤
│  External dependencies                                  │
│  └─ OpenCV (cv::Mat, cv::imread, cv::imwrite, drawing)  │
└─────────────────────────────────────────────────────────┘

Main Entry Point

Source: src/Main.cpp

main() prints a greeting, copies argv into a std::vector<std::string>, constructs a SpriteUtils instance, and calls run(args). Exceptions are not caught in main — they propagate and terminate with an unhandled exception message.

SpriteUtils — The Dispatcher

Source: include/SpriteUtils.h, src/SpriteUtils.cpp

Holds an std::unordered_map<std::string, std::unique_ptr<Command>>. In the constructor, three commands are registered:

  • "draw" → DrawCommand
  • "help" → HelpCommand
  • "version" → VersionCommand

On run(), args are parsed into SpriteUtilsArgs, the command name is extracted, the map is looked up, and Command::run() is called. If the command is unknown, help is printed and an exception is thrown.

Command Interface

Source: include/Command.h

Abstract base class with two pure-virtual-equivalent methods:

  • getName() const — returns the command's string name.
  • run(const SpriteUtilsArgs& args) — executes the command; default throws "Not yet implemented."

All concrete commands inherit from Command.

Argument Parsing

Source: include/SpriteUtilsArgs.h, src/SpriteUtilsArgs.cpp

SpriteUtilsArgs is constructed with argv (minus program name). The first element is the command name. Remaining elements are parsed in pairs: --key value. Keys must start with --; values must not. The result is stored in an std::map<std::string, std::string>.

Options Access

Source: include/SpriteUtilsOptions.h, src/SpriteUtilsOptions.cpp

SpriteUtilsOptions wraps SpriteUtilsArgs and provides typed accessors for the options known to the draw command. It maps raw string arguments to typed values (bool, int, string, Color).

Data Flow for draw Command

SpriteUtilsArgs
  └─ SpriteUtilsOptions
       ├─ getWorkingDirectory()
       ├─ getSpriteSheetPath()
       └─ ... other options

SpriteSheet(csvPath)
  ├─ Reads CSV text via Utils::readTextFromFile()
  ├─ Parses each line into SpriteSheetRow
  ├─ Validates row order and column sequence
  ├─ Computes x and height where omitted
  ├─ Groups rows by filename in map<string, vector<SpriteSheetRow>>
  └─ Writes computed CSV file

For each file in workingDir:
  ├─ Skip if .backup file
  ├─ Skip if not in --file-name filter
  ├─ Manage backup (create or restore)
  ├─ readBmpBpp() → detect bit depth
  ├─ cv::imread() → load into cv::Mat
  ├─ getSpriteSheetRows(filename) → get relevant rows
  ├─ Filter by --row if specified
  ├─ For each row:
  │   ├─ drawNumber() if enabled
  │   └─ drawDashedRect()
  └─ Save (writeBmp16BGR565 or cv::imwrite)

Error Handling

All error conditions throw SpriteUtilsException (inherits std::runtime_error). There is no try/catch in main(), so unhandled exceptions terminate the process with a default error message. The exception message is human-readable (e.g. file path + reason).

The draw command has one try/catch block around the image-write step to wrap I/O exceptions in SpriteUtilsException.

Relationship to Other Tools

sprite-utils is designed for the Open Eggbert / Free Eggbert / Galaxy Eggbert game asset pipeline. The BLP format support and the RGB565 handling are specific to the format used by those games. The tool can be invoked from build scripts or manually as part of asset preparation before game resources are packaged.
