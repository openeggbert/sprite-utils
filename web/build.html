Build

sprite-utils uses CMake as its build system and requires a C++23-capable compiler and OpenCV.

Build Steps

Standard Release Build

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Debug Build

cmake -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel

Clean Build

# Remove build directory and start fresh
rm -rf build
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Specifying OpenCV Location

If CMake cannot automatically find OpenCV, provide its path explicitly:

cmake -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DOpenCV_DIR=/path/to/opencv/lib/cmake/opencv4

Compiler Requirements

C++23 features used by sprite-utils include:

  • std::filesystem (C++17, available in all C++23 compilers)
  • std::optional
  • std::string::starts_with / std::string::ends_with (C++20)
  • std::unordered_map::contains (C++20, guarded by #if __cpp_lib_contains)
  • Range-based for with structured bindings
  • Endianness macros: __BYTE_ORDER__, __ORDER_BIG_ENDIAN__

Compilers known to support C++23:

  • GCC ≥ 13 with -std=c++23
  • Clang ≥ 17 with -std=c++23
  • MSVC ≥ 19.38 (VS 2022 17.8) with /std:c++latest

IDE Support

The repository includes a .idea/ directory, indicating the project is used with CLion (JetBrains). CMake integration in CLion is supported natively.

The .clangd file adds -std=c++23 to the compile flags, enabling accurate code analysis in editors that use clangd (VS Code with clangd extension, Neovim, etc.).

Common Build Problems

ProblemLikely CauseFix
Could not find OpenCV OpenCV not installed or not on CMake path Install OpenCV dev package; set -DOpenCV_DIR=...
Compiler error about C++23 features Compiler too old Upgrade to GCC ≥ 13 or Clang ≥ 17
Link errors with OpenCV symbols OpenCV header/library version mismatch Ensure the same OpenCV version is used for headers and libs
CMake version too old CMake < 3.25.1 installed Upgrade CMake

Tests

No Tests Present

The repository contains no test files (no test/ directory, no CTest configuration). There is no automated test suite to run. This is a known limitation; see Roadmap.
