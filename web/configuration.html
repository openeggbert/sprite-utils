Configuration

sprite-utils has no configuration file. All configuration is passed via command-line arguments. This page summarises the full set of configurable options with their defaults and valid values.

No Config File

There is no .ini, .json, or environment variable configuration. Every option must be specified on the command line each time the tool is invoked.

All Options (draw command)

OptionDefaultValid ValuesSource
--dir . Any valid directory path SpriteUtilsOptions::getWorkingDirectory()
--sprite-sheet-path <dir>/spritesheet.csv Any valid file path SpriteUtilsOptions::getSpriteSheetPath()
--file-name (none, process all) Filename string (not path) SpriteUtilsOptions::getFileName()
--row (none, all rows) Positive integer SpriteUtilsOptions::getRow()
--draw-number true true / false SpriteUtilsOptions::isDrawNumberEnabled()
--draw-number-background true true / false SpriteUtilsOptions::isDrawNumberBackgroundEnabled()
--double-sized-number false true / false SpriteUtilsOptions::isNumberDoubleSized()
--rectangle-color 255,0,0 (red) Comma-separated R,G,B integers 0–255 SpriteUtilsOptions::getRectangleColor()

Rectangle Color Format

The colour value must be exactly three comma-separated integers with no spaces:

--rectangle-color 255,0,0     # red (default)
--rectangle-color 0,255,0     # green
--rectangle-color 0,0,255     # blue
--rectangle-color 255,255,0   # yellow

Providing fewer or more than three components throws: SpriteUtilsException("Invalid format of rectangle-color option: ...")

Boolean Argument Interpretation

Boolean options compare the value string to "true" (case-sensitive). Any other value is treated as false:

--draw-number true    # enables number drawing
--draw-number false   # disables number drawing
--draw-number yes     # treated as false (not "true")

Verbose Logging

A --verbose true option is mentioned in SpriteUtilsArgs::isVerboseLoggingEnabled() but is not currently wired to any additional output. It is parsed and stored but has no effect. Needs verification
