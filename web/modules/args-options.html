Module: Args & Options

Source: include/SpriteUtilsArgs.h, src/SpriteUtilsArgs.cpp, include/SpriteUtilsOptions.h, src/SpriteUtilsOptions.cpp

Two-class argument parsing layer that separates raw parsing (SpriteUtilsArgs) from typed option access (SpriteUtilsOptions).

SpriteUtilsArgs — Raw Argument Store

Parses argv (minus program name) into a key-value map.

Constructor

SpriteUtilsArgs(std::vector<std::string>& args);

Parsing rules:

  • First element → command name (default: "draw" if args is empty)
  • Remaining elements → pairs of --key / value
  • Keys must start with --
  • Values must not start with --
  • Missing value throws SpriteUtilsException

SpriteUtilsOptions — Typed Option Access

Wraps SpriteUtilsArgs and provides methods for each known draw option.

Also declares the Color struct.

Color Struct

struct Color {
    int r{}, g{}, b{}, a{};
    static const Color RED;  // {255, 0, 0, 0}
};
