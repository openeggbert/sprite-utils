Module: SpriteSheet

Source: include/SpriteSheet.h, src/SpriteSheet.cpp, include/SpriteSheetRow.h, src/SpriteSheetRow.cpp

This module is responsible for reading, validating, computing, and storing the sprite-sheet definition from a CSV file.

Classes

SpriteSheet

Loads the CSV on construction. Validates and computes all rows. Stores them in a map<string, vector<SpriteSheetRow>> keyed by image filename.

Constructor

explicit SpriteSheet(const std::filesystem::path& file);

On construction:

  1. Reads the CSV text via Utils::readTextFromFile()
  2. Skips the header line
  3. Processes each subsequent line until skipskip
  4. For each line: parses, validates, updates coordinates, stores in map
  5. Writes <csvpath>.computed.csv

Global State Warning

lastX, lastWidth, lastHeight are declared as static class members and a static std::optional<SpriteSheetRow> at file scope. This makes SpriteSheet non-reentrant: creating two instances in the same process would share this state and produce incorrect results.

SpriteSheetRow

A plain struct-like class representing one row of the CSV. It parses from a CSV string and can serialize back to a CSV string.
