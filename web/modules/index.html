Modules

sprite-utils is organized into a small set of cohesive modules. Each module page describes the module's purpose, key classes, data flow, and source files.

ModuleKey ClassesPurpose
DrawCommand DrawCommand Core annotation engine: draws dashed rectangles and numbers on images
SpriteSheet SpriteSheet, SpriteSheetRow CSV parsing, validation, coordinate computation, computed CSV output
Args & Options SpriteUtilsArgs, SpriteUtilsOptions Command-line argument parsing and typed option access
Utils Utils File I/O, string splitting, directory listing

Module Dependencies

DrawCommand
  ├─ SpriteSheet
  │   └─ SpriteSheetRow
  │       └─ Utils (split)
  ├─ SpriteUtilsOptions
  │   └─ SpriteUtilsArgs
  └─ Utils (copyFile)
