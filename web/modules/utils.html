Module: Utils

Source: include/Utils.h, src/Utils.cpp

Static utility class providing file I/O, directory listing, and string splitting. Not intended to be instantiated (private constructor).

Methods

MethodSignatureDescription
listAllFilesInDir static vector<path> listAllFilesInDir(const path& dir) Recursively lists all files and directories under dir. Returns the dir itself as the first entry.
copyFile static void copyFile(const path& original, const path& copied) Copies a file, overwriting destination if it exists. Wraps std::filesystem::copy_file. Throws SpriteUtilsException on failure.
writeTextToFile static void writeTextToFile(const string& text, const path& file) Writes a string to a file. Throws if file cannot be opened.
readTextFromFile static string readTextFromFile(const path& file) Reads entire file to a string. Returns empty string if file does not exist. Throws if file exists but cannot be opened.
readFromInputStream static string readFromInputStream(istream& input) Reads entire istream to a string via stringstream rdbuf.
split static vector<string> split(const string& input, const string& delim = ",") Splits a string by a delimiter. Default delimiter is comma. Returns a vector of parts (always at least one element). Trailing empty parts are included.

Notes

  • split() is used with ";" as delimiter for CSV parsing.
  • split() with default "," is used for parsing the --rectangle-color option.
  • listAllFilesInDir() includes directories in the result (used internally), but the draw command uses std::filesystem::directory_iterator directly.
