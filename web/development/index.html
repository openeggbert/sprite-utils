Starting Points for New Developers

  1. Read Overview to understand the project's purpose.
  2. Build the project following Build.
  3. Read Architecture for the high-level design.
  4. Study src/Main.cpp and src/SpriteUtils.cpp — they are small and show the entry point and dispatch pattern.
  5. Study src/DrawCommand.cpp — the most substantial file; understand the image pipeline.
  6. Study src/SpriteSheet.cpp — understand CSV parsing and computed output.

Adding a New Command

  1. Create include/MyCommand.h and src/MyCommand.cpp inheriting from Command.
  2. Define static constexpr const char* NAME = "mycommand";
  3. Override getName() to return NAME.
  4. Override run(const SpriteUtilsArgs& args) with the implementation.
  5. Register in SpriteUtils::SpriteUtils(): commandImplementations.emplace("mycommand", std::make_unique<MyCommand>());
  6. Add the source file to CMakeLists.txt.

Most Important Files

  • src/DrawCommand.cpp — core logic, largest file
  • src/SpriteSheet.cpp — CSV parsing and validation
  • include/SpriteSheetRow.h — data model
  • src/SpriteUtilsOptions.cpp — all option defaults live here
  • CMakeLists.txt — build configuration
