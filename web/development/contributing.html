Contributing

How to Add a New Command

  1. Create the header in include/:

    // include/MyCommand.h
#pragma once
#include "Command.h"

class MyCommand : public Command {
public:
    static constexpr const char* NAME = "mycommand";
    std::string getName() const override { return NAME; }
    std::string run(const SpriteUtilsArgs& args) override;
};

  2. Create the implementation in src/:

    // src/MyCommand.cpp
#include "MyCommand.h"
#include <iostream>

std::string MyCommand::run(const SpriteUtilsArgs& args) {
    std::cout << "MyCommand running\n";
    return "";
}

  3. Register in src/SpriteUtils.cpp:

    commandImplementations.emplace("mycommand", std::make_unique<MyCommand>());

  4. Add to CMakeLists.txt:

    add_executable(sprite_utils
    ...
    src/MyCommand.cpp
)
  5. Update the help text in src/HelpCommand.cpp.
  6. Add the licence header using add_license_after_includes.sh.

How to Add a New Option

  1. The raw option is automatically available via SpriteUtilsArgs::getArgumentOptional("--myoption") without any code changes.
  2. Add a typed accessor to SpriteUtilsOptions:
// in SpriteUtilsOptions.h
bool isMyOptionEnabled() const;

// in SpriteUtilsOptions.cpp
bool SpriteUtilsOptions::isMyOptionEnabled() const {
    return spriteUtilsArgs.getBooleanArgument("--my-option", false);
}

Licence Header

All source files must start with the MIT licence header from header.txt. The script add_license_after_includes.sh can prepend this header after include statements.

Code Quality Notes

  • No automated tests exist; manual testing is currently required.
  • clangd static analysis is configured via .clangd.
  • Avoid introducing global or static state unless truly necessary (see known issue with SpriteSheet static fields).
