Tutorial: Using the draw Command

Goal

Annotate all sprite images in a directory with dashed rectangles so you can visually verify the sprite coordinates defined in your CSV file.

Prerequisites

  • Built binary at ./build/sprite_utils (see Building)
  • A directory of BMP image files
  • A spritesheet.csv file (see CSV Format Tutorial)

Step 1: Run draw

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --sprite-sheet-path /path/to/spritesheet.csv

Step 2: Inspect the Images

Open the annotated images in any image viewer. You should see:

  • Dashed red rectangles around each sprite position
  • Small numbers in the bottom-right of each rectangle (the sprite's sequence number)

The backup files (*.backup) preserve the clean originals. The computed CSV (spritesheet.csv.computed.csv) shows all resolved coordinates.

Step 3: Fix and Re-run

If a rectangle is wrong, edit spritesheet.csv and re-run the same command. The tool automatically restores from backup before re-annotating.

Customizing Output

Change Rectangle Color to Green

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --rectangle-color 0,255,0

Process Only One File

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --file-name player.bmp

Draw Only Row 2

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --file-name player.bmp \
  --row 2

Disable Number Drawing

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --draw-number false

Large Font Numbers (for big sprites)

./build/sprite_utils draw \
  --dir /path/to/sprites \
  --double-sized-number true

Sprites narrower than 23 pixels automatically use the small font.

Understanding Backup Behavior

First run:

player.bmp        → annotated (dashed rects drawn)
player.bmp.backup → copy of original (clean)

Second run (after editing CSV):

player.bmp.backup → exists → restore to player.bmp
player.bmp        → re-annotated with new coordinates

Don't Delete Backups

The backup files are your only copy of the original images after the first run. Keep them until you are confident the CSV is correct.
