Tutorial: Creating a CSV Sprite Sheet

Understanding the Format

The sprite-sheet CSV uses semicolons as separators (not commas). The columns are: file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet

Step 1: Create the Header

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet

This is always the first line. It is skipped by the parser and preserved in computed output.

Step 2: Add Sprite Rows

Let's say we have a player.bmp sprite sheet with a 4-frame walk animation. Each frame is 32×48 pixels arranged horizontally.

The full explicit form (all fields specified):

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
player.bmp;walk;1;1;1;0;0;32;48;;;
player.bmp;walk;2;1;2;32;0;32;48;;;
player.bmp;walk;3;1;3;64;0;32;48;;;
player.bmp;walk;4;1;4;96;0;32;48;;;

Step 3: Use Auto-Computed Fields

Leave x and height empty and let the tool compute them. For same-row sprites with uniform width, only the first row needs x=0 and height=48:

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
player.bmp;walk;1;1;1;;0;32;48;;;
player.bmp;walk;2;1;2;;;32;0;;;
player.bmp;walk;3;1;3;;;32;0;;;
player.bmp;walk;4;1;4;;;32;0;;;

Column 1: x empty → computed as 0. height=48 explicitly set.
Columns 2-4: x empty → computed as previous x + previous width. height=0 → inherited from previous row (48).

First Row Rule

The first row for each image file must have row=1 and column=1. The numberPerSheet field is always computed — set it to empty or 0.

Step 4: Multiple Images

You can include multiple image files in the same CSV. Group them together — once the parser sees a new filename, it resets the row/column counter:

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
player.bmp;walk;1;1;1;;0;32;48;;;
player.bmp;walk;2;1;2;;;32;0;;;
enemy.bmp;idle;1;1;1;;0;24;24;;;
enemy.bmp;idle;2;1;2;;;24;0;;;

Step 5: Multiple Rows on a Sheet

If your sheet has rows of sprites stacked vertically, use row=2 for the second row. The y value must be set for the first sprite of each new row:

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
player.bmp;walk;1;1;1;;0;32;48;;;
player.bmp;walk;2;1;2;;;32;0;;;
player.bmp;run;1;2;1;;48;40;40;;;
player.bmp;run;2;2;2;;;40;0;;;

Step 6: Add a Skip Sentinel (Optional)

Add skipskip anywhere in the file to stop parsing at that point. Useful for commenting out rows or adding notes below:

...
skipskip
# These rows are disabled for now
player.bmp;jump;1;3;1;;88;32;64;;;

Step 7: Save as spritesheet.csv

Save the file as spritesheet.csv in your image directory. You can also use a different name and specify it with --sprite-sheet-path.
