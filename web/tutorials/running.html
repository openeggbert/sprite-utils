Tutorial: Running sprite-utils

Check the Binary Works

./build/sprite_utils version
# Sprite Utils - tool used to work with sprites
# Sprite Utils 0.0.0-SNAPSHOT

./build/sprite_utils help

Both commands should print without errors.

Typical Invocation

./build/sprite_utils draw \
  --dir /path/to/your/sprites \
  --sprite-sheet-path /path/to/spritesheet.csv

Expected Stdout

You will see output similar to:

Sprite Utils - tool used to work with sprites
Found arg: --dir=/path/to/sprites
Found arg: --sprite-sheet-path=/path/to/spritesheet.csv
Found argument: --dir = /path/to/sprites
Found argument: --sprite-sheet-path = /path/to/spritesheet.csv
Going to process images in directory: "/path/to/sprites"
player.bmp;walk;1;1;1;0;0;32;32;;;1
player.bmp;walk;2;1;2;32;0;32;32;;;2
...

After Running

In your sprite directory you will find:

  • player.bmp — annotated image with red dashed rectangles and numbers
  • player.bmp.backup — copy of the original image
  • spritesheet.csv.computed.csv — computed version of the CSV with resolved values

Verifying Results

Open the annotated image in any image viewer. Each sprite region should have:

  • A dashed red border around it
  • A small number in the bottom-right of the rectangle (unless --draw-number false)

If a rectangle is misaligned, fix the corresponding row in spritesheet.csv and re-run. The tool will restore from backup before re-drawing.
