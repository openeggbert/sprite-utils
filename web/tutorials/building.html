Tutorial: Building sprite-utils

1. Install Prerequisites

On Debian/Ubuntu:

sudo apt-get update
sudo apt-get install -y \
  build-essential \
  cmake \
  libopencv-dev \
  git

On Fedora:

sudo dnf install -y gcc-c++ cmake opencv-devel git

On macOS (Homebrew):

brew install cmake opencv git

2. Clone the Repository

git clone https://github.com/openeggbert/sprite-utils.git
cd sprite-utils

3. Configure the Build

cmake -B build -DCMAKE_BUILD_TYPE=Release

Expected output includes lines like:

-- Found OpenCV: /usr (found version "4.x.x")
-- Configuring done
-- Build files have been written to: .../sprite-utils/build

4. Compile

cmake --build build --parallel

On success, the binary is at build/sprite_utils.

5. Verify

./build/sprite_utils version
# Expected: Sprite Utils 0.0.0-SNAPSHOT

Troubleshooting

OpenCV Not Found

cmake -B build \
  -DOpenCV_DIR=/path/to/opencv/lib/cmake/opencv4

C++23 Error

Upgrade your compiler: GCC ≥ 13 or Clang ≥ 17 is required.

Clean Build

rm -rf build
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
