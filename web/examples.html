Examples

Practical command invocations derived from the source code. All examples assume the binary is at ./build/sprite_utils.

Example 1: Annotate All Files in Current Directory

cd /game/assets
sprite_utils draw

Uses spritesheet.csv in the current directory. Annotates all image files that have matching entries.

Example 2: Explicit Directory and CSV Path

sprite_utils draw \
  --dir /game/assets/sprites \
  --sprite-sheet-path /game/config/sprites.csv

Example 3: Single File, Specific Row

sprite_utils draw \
  --dir /game/assets \
  --file-name player.bmp \
  --row 2

Only annotates sprites in row 2 of the player.bmp image.

Example 4: Green Rectangles, No Numbers

sprite_utils draw \
  --dir /game/assets \
  --rectangle-color 0,255,0 \
  --draw-number false

Example 5: Double-Sized Numbers with Background

sprite_utils draw \
  --dir /game/assets \
  --double-sized-number true \
  --draw-number-background true

Automatic Fallback

If a sprite's width is less than 23 pixels, the large font automatically falls back to the small 3×5 font even when --double-sized-number true is set.

Example 6: Minimal CSV

A sprite-sheet CSV for a 64×64 image with a 4-frame walk animation in a single row:

file;group;numberInGroup;row;column;x;y;width;height;notes;tags;numberPerSheet
character.bmp;walk;1;1;1;;0;16;16;;;
character.bmp;walk;2;1;2;;;16;0;;;
character.bmp;walk;3;1;3;;;16;0;;;
character.bmp;walk;4;1;4;;;16;0;;;

Note that for columns 2–4, x and height are left empty. The tool computes x as the previous x + previous width (16, 32, 48) and height as inherited from the first row (16).

Example 7: Check Version

sprite_utils version
# Output: Sprite Utils 0.0.0-SNAPSHOT

Example 8: Display Help

sprite_utils help

Prints all available commands and their options to stdout.

Example 9: Pipeline Script

A simple shell script to annotate multiple asset directories:

#!/bin/bash
BINARY=./build/sprite_utils
CSV=/game/config/spritesheet.csv

for dir in /game/assets/chars /game/assets/items /game/assets/tiles; do
    echo "Processing $dir..."
    "$BINARY" draw \
      --dir "$dir" \
      --sprite-sheet-path "$CSV"
done
echo "Done."
