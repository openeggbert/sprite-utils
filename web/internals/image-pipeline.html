Image Pipeline

Source: src/DrawCommand.cpp, DrawCommand::run()

Overview

The pipeline runs once per file in the working directory. Here is the annotated pseudocode:

DrawCommand::run(SpriteUtilsArgs args):
  opt = SpriteUtilsOptions(args)
  workingDir = opt.getWorkingDirectory()
  spriteSheet = SpriteSheet(opt.getSpriteSheetPath())

  for each entry in directory_iterator(workingDir):
    if not regular_file: continue
    imageFile = entry.path()

    // File name filter
    if opt.getFileName() is set
      AND imageFile.filename() != opt.getFileName(): continue

    // Skip backup files
    if filename.ends_with(".backup"): continue

    // Backup management
    backup = imageFile + ".backup"
    if backup exists:
      remove(imageFile)
      copyFile(backup → imageFile)   // restore clean original
    else:
      copyFile(imageFile → backup)   // create first backup

    // Bit-depth detection (BMP/BLP specific)
    bpp = readBmpBpp(imageFile)

    // Load image into OpenCV Mat
    img = cv::imread(imageFile, IMREAD_UNCHANGED)
    if img.empty(): throw error

    // Grayscale → BGR conversion
    if img.channels() == 1:
      cvtColor(img, img, COLOR_GRAY2BGR)

    // Get sprite rows for this file
    rows = spriteSheet.getSpriteSheetRows(filename)
    if rows.empty():
      if file-name filter active AND matched: break
      else: continue

    // Row filter
    if opt.getRow() is set:
      filter rows to only those with matching row number

    // Draw annotations
    for each row in todo:
      doubleSize = opt.isNumberDoubleSized()
      if doubleSize AND row.width < 23: doubleSize = false

      if opt.isDrawNumberEnabled():
        endX = row.x + row.width - 1
        endY = row.y + row.height - 1
        drawNumber(img, row.numberPerSheet, endX-2, endY-1, doubleSize, opt)

      col = toScalar(opt.getRectangleColor())
      rc = Rect(row.x, row.y, max(1, row.width), max(1, row.height))
      drawDashedRect(img, rc, col)

    // Save preserving original bit-depth
    ext = lowercase(imageFile.extension())
    if ext == ".blp":          writeBmp16BGR565(imageFile, img)
    else if bpp == 16:         writeBmp16BGR565(imageFile, img)
    else if bpp == 8:          cv::imwrite(imageFile, img)
    else:                      cv::imwrite(imageFile, img)

    // Stop early if single-file mode
    if file-name filter active AND matched: break

Key Observations

  • Files with no matching CSV rows are silently skipped (not an error).
  • The readBmpBpp() call is made for every file regardless of extension; it will throw if the file is not a valid BMP. For non-BMP files (PNG, JPEG), this means the function will throw because the file won't have a BM signature. Needs verification — in practice, the code may crash or silently fall through depending on OpenCV error handling before this call.
  • The minimum rectangle size is 1×1 pixel (max(1, width) and max(1, height)).
  • Number positioning: right edge at x + width - 3, bottom edge at y + height - 2.

Non-BMP File Handling

The readBmpBpp() function is called on every file before cv::imread. For non-BMP files, it will throw because the BMP signature check fails. This means non-BMP image files in the working directory that have CSV entries may cause the tool to terminate with an exception rather than processing them through OpenCV. This appears to be a bug. Needs verification
