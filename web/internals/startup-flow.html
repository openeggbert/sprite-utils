Startup Flow

Step 1: main()

Source: src/Main.cpp

int main(int argc, char* argv[]) {
    std::cout << "Sprite Utils - tool used to work with sprites" << std::endl;
    std::vector<std::string> args(argv + 1, argv + argc);
    SpriteUtils spriteUtils;
    spriteUtils.run(args);
}
  1. Print greeting to stdout.
  2. Copy argv[1..argc-1] into a vector<string> (skips program name).
  3. Construct SpriteUtils (registers commands in map).
  4. Call run(args).
  5. If anything throws, the exception propagates uncaught, printing the exception message and terminating.

Step 2: SpriteUtils Constructor

Source: src/SpriteUtils.cpp

SpriteUtils::SpriteUtils() {
    commandImplementations.emplace("draw",    std::make_unique<DrawCommand>());
    commandImplementations.emplace("help",    std::make_unique<HelpCommand>());
    commandImplementations.emplace("version", std::make_unique<VersionCommand>());
}

Three command instances are registered. No other initialization occurs.

Step 3: SpriteUtils::run(vector<string>)

void SpriteUtils::run(const std::vector<std::string>& args) {
    SpriteUtilsArgs parsedArgs(const_cast<std::vector<std::string>&>(args));
    run(parsedArgs);
}

Parses args into SpriteUtilsArgs, then delegates.

const_cast Usage

The const_cast here is a code smell — SpriteUtilsArgs constructor takes a non-const reference but does not modify the vector. This should eventually be fixed to take const vector<string>&.

Step 4: SpriteUtils::run(SpriteUtilsArgs)

void SpriteUtils::run(const SpriteUtilsArgs& spriteUtilsArgs) {
    std::string commandName = spriteUtilsArgs.get_command();
    auto it = commandImplementations.find(commandName);
    if (it == commandImplementations.end()) {
        std::cerr << "Command \"" << commandName << "\" is not supported.\n\n";
        HelpCommand help;
        help.run(spriteUtilsArgs);
        throw SpriteUtilsException("Command \"" + commandName + "\" is not supported.");
    }
    std::string result = it->second->run(spriteUtilsArgs);
    (void)result;
}
  1. Extract command name from parsed args.
  2. Look it up in the map.
  3. If not found: print error to stderr, show help, throw exception.
  4. If found: call Command::run(). Return value is discarded.

Step 5: Command Execution

Each command receives the full SpriteUtilsArgs and does its work. The return value (a string) is currently unused.
