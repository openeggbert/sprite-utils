Roadmap

This page documents planned features that are visible from the source code but not yet implemented. All items here are inferred from repository evidence only.

Evidence Source

The SpriteUtilsCommand enum in include/SpriteUtilsCommand.h lists: DRAW, RESTORE, EXTRACT, GIFS, HELP, VERSION. Only DRAW, HELP, and VERSION are currently wired in SpriteUtils.cpp.

Planned Commands

restore Planned

Would restore all image files in the working directory from their .backup counterparts. Currently this must be done manually by copying backup files.

Evidence: RESTORE in the SpriteUtilsCommand enum.

extract Planned

Would extract individual sprites from sprite sheets into separate image files, one per sprite rectangle. This is the core "cutting" operation that sprite-utils currently cannot perform.

Evidence: EXTRACT in the SpriteUtilsCommand enum.

gifs Planned

Would generate animated GIFs from sprite groups (animation frames). Likely intended to produce preview animations from the defined sprite groups.

Evidence: GIFS in the SpriteUtilsCommand enum.

Other Improvements (Suggested)

These are improvements visible as gaps from the current source code, not explicitly planned:

  • Tests — no test suite exists; unit tests for CSV parsing and image processing would prevent regressions.
  • Fix help text — the help command output references options that don't match the actual implementation.
  • Error recovery — currently any error terminates the process; a --continue-on-error mode would be useful for batch processing.
  • Fix global state — SpriteSheet uses static class members which makes it non-reentrant.
  • Config file support — avoid re-specifying all options on every invocation.
  • Recursive directory processing — currently only processes files in the top-level of --dir.
